# ODMANI — Android nativo

Página de download e instalador de teste do ODMANI.

Aplicativo desenvolvido em Kotlin e Jetpack Compose, com leitura offline de PDFs, biblioteca, pastas, categorias, temas e estatísticas locais.

Versão: 2.0.0-alpha03. Android 8 ou posterior.

Para atualizar a alpha nativa anterior, instale o APK sem desinstalar. A biblioteca e as preferências são preservadas. Ainda é uma versão de testes; a validação física no Moto G84 permanece necessária.

Este repositório publica a página, o ícone e o APK. Não inclui chaves privadas, documentos pessoais ou o projeto-fonte completo do aplicativo.

Atualização visual Light & Dark: Soft UI, capas originais da primeira página, cache local e listas sob demanda. O conteúdo e as cores dos PDFs não são alterados pelos temas.
